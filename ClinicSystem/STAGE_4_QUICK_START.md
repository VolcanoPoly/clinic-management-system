## Database Interactions

### When Creating a Doctor:
1. Creates `ApplicationUser` record
2. Hashes password with Identity
3. Creates `Doctor` record linked to user
4. Adds `DoctorSpecialization` records
5. Creates 5 `DoctorSchedule` records (Mon-Fri, 9AM-5PM)

### When Editing Schedule:
1. Updates `DoctorSchedule` records by day
2. Validates time format (HH:mm)

### When Managing Leave:
1. Creates `DoctorLeave` records
2. Validates date ranges
3. Allows deletion of leave records

## API Endpoint Notes

These routes are automatically generated by ASP.NET Core conventions:
- Route Template: `/{Controller}/{Action}/{id}`
- All methods return `IActionResult` or `Task<IActionResult>`
- HTTP methods automatically inferred from method names

### Implicit HTTP Methods:
- `GET` - Actions without parameters or [HttpPost]
- `POST` - Actions with [HttpPost] or form submissions
- `DELETE` - Handled via POST (forms can't do DELETE)

## Troubleshooting

### Issue: "Access Denied" when accessing /Manager
- **Solution:** Login with manager account (manager@medcenter.com)

### Issue: Doctor not appearing in list
- **Solution:** Verify doctor was created (check database)
- **Solution:** Ensure DoctorSpecialization records exist

### Issue: Schedule shows incorrect times
- **Solution:** Verify DoctorSchedule records exist in database
- **Solution:** Check time format is HH:mm (24-hour)

### Issue: Cannot select specializations
- **Solution:** Verify Specialization records are seeded in database
- **Solution:** Run database migrations if needed
